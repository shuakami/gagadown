# GaGaDown 隐私政策

最后更新：2026 年 11 月 16 日

GaGaDown 是开源下载器及其浏览器扩展。本政策说明扩展和桌面程序如何处理数据、数据用途、保存位置及删除方法。

## 单一用途与有限使用

扩展的单一用途是把用户发起的浏览器下载交给同一设备上的 GaGaDown 桌面程序。扩展不会将下载信息发送给 GaGaDown 运营的服务器，不用于广告、信用评估或贷款，不出售数据，也不向数据经纪商提供数据。通过扩展取得的数据仅用于下载接管及维持该功能所必需的安全操作。

## 首次使用、同意及权限

扩展安装后默认关闭，不会监测请求或接管下载。首次设置时，用户先输入桌面程序提供的配对码并验证本机连接，然后单独授权 `cookies`、`webRequest` 和 HTTP/HTTPS 网站访问等可选浏览器权限。授权后，扩展再显示数据处理说明；只有用户明确勾选同意并点击“同意并启用”后，扩展才会开始监测请求或接管下载。拒绝权限或未同意数据处理时，接管功能保持关闭。用户可随时关闭功能；关闭操作会清除请求缓存、撤销这些可选权限并撤回本地同意状态。

此网站访问权限用于监听用户所访问 HTTP/HTTPS 网站的下载请求，并在用户启动下载时读取相关 Cookie。它可能使扩展短暂处理与下载无关的请求 URL 和请求头，以便识别下载来源。扩展不会读取 HTTPS 页面正文、密码字段或网页消息。

## 扩展处理的数据

在用户同意并启用后，扩展会在内存中暂存 HTTP/HTTPS 请求 URL、请求方法和请求头，以匹配浏览器下载。最多缓存 400 条，每条不超过 5 分钟；匹配后删除对应记录，关闭功能或撤销网站权限时清空缓存。该缓存不写入扩展持久化存储。

对于被接管的下载，扩展会把下载 URL、文件名、来源页、可用的文件大小和 MIME 类型、浏览器 User-Agent、必要请求头及 Cookie 发送给本机桌面程序。Cookie 和请求头可能含有网站登录凭据。它们仅用于继续该下载。普通自动接管仅尝试 GET 请求；右键菜单的“使用 GaGaDown 下载”是用户主动选择的下载操作，也会把所选资源 URL、页面地址及该资源可用的 Cookie 和必要请求头交给桌面程序。`data:` 资源由浏览器直接下载。

扩展通过 `127.0.0.1` 回环地址与本机程序通信。用户需从桌面程序的插件页复制本机随机配对码并输入扩展；扩展将其保存在浏览器本地扩展存储，并随 API 请求发送。桌面 API 同时校验配对码和浏览器扩展 Origin，拒绝没有 Origin、`null` Origin、非扩展 Origin 或无效配对码的请求。配对码仅用于保护本机 API，不会传出设备。本机 API 不会把任务内容转发到 GaGaDown 服务器。若本机程序未运行或不接受任务，浏览器会继续其下载。

扩展只在 `chrome.storage.local` 保存启用及同意状态、桌面程序提供的最小接管文件大小和本机 API 配对码，不持久保存 Cookie、请求头或下载历史。关闭功能或撤销授权后不再读取请求信息。移除扩展或清除扩展数据会删除这些设置。

## 桌面程序本地保存

桌面程序会保存任务 URL、来源页、Cookie、请求头、User-Agent、文件名、任务状态、错误日志和删除记录，以支持下载、恢复和历史显示。任务状态文件使用随机 AES-256-GCM 密钥加密；密钥保存在操作系统密钥环（macOS 钥匙串、Windows 凭据存储或 Linux Secret Service）。若系统密钥环不可用或无法解密，程序会拒绝读取任务状态，而不会将其当作空历史覆盖。旧版本未加密的任务状态会在密钥成功创建后迁移为加密文件。应用设置及服务器线路统计文件不包含下载 Cookie 和请求头，仍以普通本地文件保存。

任务记录保存在 GaGaDown 本地数据目录。活动任务保留到用户删除；“最近删除”记录按应用设置中的期限清理，默认期限为 7 天。删除任务记录不会自动删除已完成的下载文件。卸载应用不会保证自动清理数据目录或下载文件；用户可通过操作系统手动删除它们。任何能够访问已登录操作系统账户及其密钥环的本机进程都可能以该账户权限访问数据。

## 下载站点和第三方服务

桌面程序使用用户提交的下载 URL、Cookie 和请求头连接对应下载站点；该站点会像处理普通下载请求一样收到这些数据，并受其自身隐私政策约束。

当用户查看服务器 IP/地区信息时，桌面程序会通过 HTTPS 向 `uapis.cn` 查询下载服务器的 IP 和地区。该服务会看到查询的 IP，以及发起查询的网络出口 IP。若获得国家/地区代码，程序会从 `flagcdn.com` 通过 HTTPS 获取旗帜图片。用户设置的 `UAPI_KEY`（若存在且格式有效）会作为 Bearer 凭据发送给 `uapis.cn`。

用户启用本地代理自动探测时，GaGaDown 会检测本机常见代理端口，并可能经可用代理向 `www.gstatic.com`、`cp.cloudflare.com` 或 `connectivitycheck.platform.hicloud.com` 发送 HTTPS 连通性测试请求。相关服务可能看到代理网络出口 IP 和普通连接元数据。测试不包含下载任务的 Cookie 或授权请求头。

GaGaDown 不运营账户、广告或遥测服务。除用户选择的下载站点、上述地区信息和连通性服务外，程序不会把任务数据提供给其他第三方。

## 用户控制和联系

用户可在扩展弹出窗口关闭接管并撤销网站权限，也可在浏览器扩展管理页面移除扩展。用户可在桌面程序删除任务或清空“最近删除”；如需彻底移除本地数据，请按操作系统方式删除 GaGaDown 数据目录。

GaGaDown 不面向儿童，也不会有意收集儿童个人信息。政策更新会发布在本仓库。隐私或支持问题可通过 [GitHub Issues](https://github.com/shuakami/gagadown/issues) 联系维护者。请勿在公开 issue 中粘贴私人下载 URL、Cookie 或授权请求头。
